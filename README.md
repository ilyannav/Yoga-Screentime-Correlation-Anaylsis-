# Yoga-Screentime-Correlation-Anaylsis-
A data science project using R to explore the relationship between yoga participation and daily screen time. Using a 30-day habit-tracking dataset from Kaggle, the analysis examines whether practicing yoga is associated with changes in screen usage patterns.


How Does Daily Yoga Impact Screen Time Habits?

Overview

This project explores whether practicing yoga is associated with changes in daily screen time habits. Using the Yoga_Screen_Time_Dataset from Kaggle by Taylor L. Bailey, the analysis compares screen usage on days when yoga was practiced versus days when it was not.

The dataset contains approximately one month of daily observations, including total screen time, screen use categories (social networking, productivity, and entertainment), and whether yoga was completed on a given day.

Research Question

Does practicing yoga have an effect on daily screen time usage?

Objective

The goal of this analysis is to determine whether there is a noticeable difference in total screen time between yoga and non-yoga days.

Methods

The dataset was analyzed using R in Google Colab. The data was divided into two groups:

* Days when yoga was practiced
* Days when yoga was not practiced

For each group, the analysis examined:

* Average total screen time
* Standard deviation of screen time
* Number of observations

The average screen time provides an estimate of whether screen use tends to be higher or lower on yoga days, while the standard deviation measures how consistent screen usage is within each group.

Technologies Used

* R
* Google Colab
* Kaggle Dataset
* Data Visualization
* Descriptive Statistics

Key Findings

The results suggest that practicing yoga may be associated with lower screen time usage within this dataset. However, the findings should be interpreted cautiously due to the dataset's size and design.

Limitations

Several limitations should be considered:

* The dataset contains observations from only one individual.
* The study is observational rather than experimental.
* Potential confounding factors such as workload, day of the week, stress levels, or personal habits may influence screen time.
* Results cannot be generalized to larger populations.

Conclusion

This analysis suggests a possible association between yoga practice and reduced screen time for the individual represented in the dataset. While the findings may be useful for personal reflection and habit tracking, additional research with larger and more diverse samples would be needed to determine whether this relationship exists more broadly.

Data Source

Taylor L. Bailey, Yoga Screen Time Dataset (Kaggle)
